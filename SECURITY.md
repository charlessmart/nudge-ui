# Security

Nudge UI is a development-only inspector. Do not connect it to production data
or untrusted pages.

Report suspected vulnerabilities privately through the repository's [GitHub
Security Advisories](https://github.com/charlessmart/nudge-ui/security/advisories/new)
instead of a public issue. Include the affected version, environment,
reproduction steps, and impact. Do not include credentials or private customer
data.
