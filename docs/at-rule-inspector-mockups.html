Three ways to expose rule context

All examples inspect the same heading. Its base value is 24px, while the active small-screen media rule sets it to 20px. The key is to make the current source context obvious without turning the inspector into a stylesheet editor.

A. Context ribbon

Smallest intervention: always edit the currently winning authored context. The active rule is visible before the fields, while the full list stays behind one “View variants” affordance.
