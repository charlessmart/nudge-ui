# Domain docs

This repository intentionally has no `CONTEXT.md`.

Before planning or implementing work, read the material relevant to the task:

- `PLAN.md` for product scope and architecture.
- `docs/adr/` for immutable technical decisions.
- `docs/features/` for approved or in-progress larger feature plans.

Use the terms established in those documents. If a proposal conflicts with an
ADR, state the conflict rather than silently overriding the decision.
