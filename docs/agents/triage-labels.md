# Triage labels

The local issue tracker uses these canonical labels:

| Triage role | Local label | Meaning |
| --- | --- | --- |
| Maintainer evaluation | `needs-triage` | Needs evaluation and prioritisation. |
| Waiting on reporter | `needs-info` | Cannot progress without more information. |
| Ready for an agent | `ready-for-agent` | Fully specified and safe to implement autonomously. |
| Ready for a human | `ready-for-human` | Requires a human decision or implementation. |
| Not planned | `wontfix` | Will not be actioned. |

New issues begin with `needs-triage` unless their status is explicitly agreed.
