Design Tool reference

CSSOM value trace

The shortest useful model for following a style from authored CSS into the inspector.

Four facts, kept separate

FactMeaningRepository representation
AuthoredThe declaration text the author wrote.authored, declaredValue
Token attributionThe project/framework token references found in authored CSS.tokenName, tokens
ComputedThe browser's value after cascade, inheritance, substitution, and computation.computed, often resolvedValue
Edit capabilityWhat the UI can change without losing authored meaning.capability

Runtime algorithm

  1. Walk document.styleSheets and each sheet's cssRules.
  2. Recover authored declaration text for same-document style elements.
  3. Match selector branches against the selected element.
  4. Compare importance, layers, specificity, and source order.
  5. Resolve var() references, aliases, fallbacks, opacity, and safe shorthands.
  6. Read getComputedStyle() to validate what the browser paints.
  7. Project rows into fields, then write edits to the managed stylesheet.

Diagnostic question

If a field shows 16px but the source says var(--space-4), that is not a contradiction. The first is computed output; the second is authored intent. A trustworthy inspector needs both.
