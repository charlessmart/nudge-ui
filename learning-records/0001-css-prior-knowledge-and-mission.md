# CSS pipeline learning baseline

The user already understands ordinary CSS styling rules and shorthands, has a rough understanding of Tailwind, and has limited familiarity with Sprinkles and other styling systems. The learning mission is to become able to trace and extend this repository's authored-CSS, CSSOM, computed-style, token-adapter, and inspector-UI pipeline; future lessons should start from that CSS foundation rather than re-teaching basic selectors or shorthand syntax.
